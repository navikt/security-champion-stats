# Security Champion App

This repository contains both backend and frontend code for the Security Champion app. The application acts as a hub
for security champions — covering everything from joining or leaving the program, to seeing the community, upcoming
events, and much more. It also serves a secondary purpose for the appsec team to track the success of the program
and appsec work.

For more information, read the respective README files in [`apps/backend`](apps/backend/Readme.md) and
[`apps/frontend`](apps/frontend/Readme.md).
